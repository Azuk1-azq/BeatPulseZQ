Features

遊んで、創って、競える。

ゲームからエディタ、オンライン共有まで、ひとつのアプリにそろっています。

本格リズムゲーム

D F J K・矢印キー・PS4コントローラー・スマホのタッチに対応。ホールドノーツや範囲別スクロール速度も。

MV(動画)を背景に

MP4などの動画を読み込めば、ミュージックビデオを背景にプレイ。不透明度も調整できます。

直感的な譜面エディタ

再生しながらリアルタイム入力、スナップ・BPM・波形表示、リズム自動調整。スマホでも編集できます。

オンラインで共有

作った譜面をアップロード。曲つきの投稿も、他の人の譜面のダウンロードもワンクリックです。

曲ごとのランキング

オンライン曲を最後まで遊べばランキングに登録。アカウントに自己ベストも保存されます。

リザルトの評価

精度とS〜Dのランク、FULL COMBO / ALL PERFECT のバッジで、プレイを振り返れます。

テーマ・アクセントカラー

ダーク / ライト / システム連動と、5色のアクセントカラー。判定調整や演出のON/OFFも。

オート演奏 (β)

譜面の確認や練習に。オート演奏中はスコアが1/4になり、ランキングには登録されません。

ドラッグ&ドロップ

曲・MV・譜面JSONをウィンドウへドロップするだけ。難易度違いの譜面はまとめて読み込めます。

Game Play

どういうゲーム？

上から流れてくるノーツを DFJK やコントローラーでタイミングよく押して楽しむリズムゲームです。爽快な打鍵感と美しいビジュアルが特徴。対応しているファイル形式なら、背景にMVを表示しながらプレイすることもできます。

Beatmap Editor

譜面を簡単に作成

専用のエディタなら、誰でも簡単に譜面を作れます。音楽を再生しながらリアルタイムでノーツを配置したり、マウスとキーボードで精密に作成することも。作った譜面はJSON形式で保存・管理できます。

Online Features

インターネット機能

作った譜面をインターネットに公開して、世界中のプレイヤーに遊んでもらえます。アップロードの前に必ず 利用規約 をご確認ください。もちろん、他のクリエイターの譜面をダウンロードして遊ぶこともできます。
