利用規約

最終更新日：2026年9月20日

この利用規約（以下「本規約」）は、BeatPulse ZQ（以下「本サービス」）の利用条件を定めるものです。

本サービスを利用することで、本規約に同意したものとみなされます。

第1条サービスについて

BeatPulse ZQは、音楽を楽しんだり、ユーザーが制作した楽曲・創作譜面などを共有したりするためのサービスです。

ユーザーは、本規約および適用される法律・規則を守って本サービスを利用してください。

第2条楽曲・音源の投稿

ユーザーは、本サービスに楽曲・音源などを投稿することができます。
ただし、投稿する音源について、投稿者自身が本サービス上で公開・再生するために必要な著作権その他の権利・許諾を有している必要があります。

第三者が著作権その他の権利を有する音源を、必要な許諾なく投稿してはいけません。

また、以下のような音源の投稿を禁止します。

  • 他人が不快・苦痛に感じることを目的とした音声・音源
  • 大きな音量や不快な音などを利用して、他のユーザーを困らせることを目的とした音源
  • 他人への嫌がらせを目的とした音源
  • 法令や公序良俗に反する音源
  • 第三者の権利を侵害する音源
  • その他、本サービスの運営上不適切と判断される音源

第3条アップロード機能の悪用禁止

本サービスの楽曲アップロード機能を、本来の目的以外で悪用してはいけません。
特に、以下のような行為を禁止します。

  • 大量のファイルを送信するなどして、本サービスの正常な動作を妨害する行為
  • サービスやサーバーに過度な負荷をかける行為
  • 不正なファイルや悪意のあるデータを投稿する行為
  • 他のユーザーに迷惑をかける目的でアップロード機能を利用する行為
  • アップロード機能の脆弱性や仕様上の問題を悪用する行為
  • その他、運営がアップロード機能の悪用と判断する行為

第4条本サービスのHTML・システム等について

本サービスのHTML、JavaScript、Firebaseその他のシステムを解析・改変・悪用し、本サービスまたは他のユーザーに不正な影響を与える行為を禁止します。
特に、以下のような行為を禁止します。

  • Firebaseを不正に利用する行為
  • 本サービスのデータを不正に取得・変更・削除する行為
  • 本サービスの認証・データベース・ストレージ等を不正に利用する行為
  • 本サービスの仕様上の問題を利用して、通常ではできない操作を行う行為
  • 本サービスやサーバーに対する攻撃・妨害行為

※ただし、本サービスをフォークして独自のサービスを制作する場合など、正当な目的でFirebase等を利用することについては、本条の「悪用」には該当しません。

第5条投稿されたコンテンツの削除

運営は、以下の場合に、ユーザーへの事前の通知なく、投稿された楽曲・音源・譜面その他のコンテンツを削除することがあります。

  • 本規約に違反している場合
  • 著作権その他の権利を侵害している、または侵害しているとの申し立てがある場合
  • 他のユーザーへの迷惑行為となる場合
  • 本サービスの運営に支障をきたす場合
  • 法令に違反する場合
  • その他、運営上削除が必要と判断した場合

削除されたコンテンツについて、運営は復元を保証しません。

第6条利用停止・BAN等の措置

ユーザーが本規約に違反した場合、または本サービスの安全な運営を妨げる行為を行った場合、運営は以下の措置を行うことがあります。

  • 投稿の削除
  • 投稿機能の制限
  • アカウントの利用停止
  • BAN（本サービスの利用禁止）
  • その他、本サービスの運営に必要な措置

なお、通常の範囲で本サービスを利用しているユーザーに対して、理由なくBAN等の措置を行うことを目的としているものではありません。

第7条IPアドレス等の情報

本サービスでは、不正利用・荒らし・攻撃・規約違反への対応、サービスの安全性確保などを目的として、必要に応じてIPアドレス等の技術的な情報を取得・利用することがあります。

取得した情報は、本サービスの運営、セキュリティ対策、不正利用への対応など、必要な目的の範囲で利用します。

通常どおり本サービスを利用しているユーザーについて、IPアドレスを取得すること自体を理由として不利益な措置を行うものではありません。

第8条著作権等

ユーザーが投稿したコンテンツについて、その著作権その他の権利は、原則として投稿者または正当な権利者に帰属します。

ユーザーは、投稿するコンテンツについて、本サービス上で公開・再生・表示するために必要な権利・許諾を取得していることを保証するものとします。

第三者から著作権その他の権利について申し立てがあった場合、運営は必要に応じて当該コンテンツを削除することがあります。

第9条禁止事項

ユーザーは、以下の行為を行ってはいけません。

  • ✕ 法令に違反する行為
  • ✕ 他人の権利を侵害する行為
  • ✕ 他のユーザーへの嫌がらせ
  • ✕ 本サービスへの不正アクセス
  • ✕ 本サービスの正常な動作を妨害する行為
  • ✕ アップロード機能の悪用
  • ✕ Firebase等のバックエンドサービスの不正利用
  • ✕ 本サービスの脆弱性を悪用する行為
  • ✕ 他のユーザーになりすます行為
  • ✕ 運営や他のユーザーに損害を与える行為
  • ✕ その他、運営が不適切と判断する行為

第10条サービスの変更・停止

運営は、必要に応じて、本サービスの内容を変更、追加、削除または停止することがあります。

メンテナンス、障害、セキュリティ上の問題その他の事情により、予告なくサービスを停止する場合があります。

第11条免責事項

運営は、本サービスについて、常に正常に動作すること、すべてのユーザーの環境で利用できること、投稿されたコンテンツが永久に保存されることを保証するものではありません。

本サービスの利用によってユーザーに生じた損害について、法令上認められる範囲で、運営は責任を負わないものとします。

第12条規約の変更

運営は、必要に応じて本規約を変更することがあります。

変更後の規約は、本サービス上に掲載した時点から適用されます。

重要な変更については、可能な限りユーザーに分かりやすい方法で告知します。

第13条お問い合わせ

本規約や投稿されたコンテンツについてのお問い合わせは、本サービスに用意されたお問い合わせ方法から行ってください。

BeatPulse ZQをみんなで安全に楽しむために

BeatPulse ZQは、音楽や創作を楽しむためのサービスです。

普通に曲を作ったり、権利を守って音源を投稿したり、創作譜面を楽しんだりする限り、安心して利用してください。

みんなが楽しく利用できるよう、アップロード機能やサービスのシステムを悪用したり、他の人が嫌がるコンテンツを投稿したりすることはやめましょう。
